Forces

Repulsion (Charge) 300

Higher values increase repulsion between nodes. Zero disables repulsion.

Leaf Repulsion (Charge) 300

Repulsion for terminal/leaf nodes only. Use different values to separate leaves from internal nodes.

Topology Repulsion Equation: Ftopology = B × (A + X) / D

Where: A = baseline offset, B = force scale, X = master control, D = graph distance

Topology Baseline (A) 1

Baseline contribution. At A=0, repulsion depends entirely on X.

Topology Multiplier (B) 1

Overall force scale. Larger values amplify the topology repulsion effect.

Topology Strength (X) 0

Master control strength. Zero disables topology repulsion completely.

Link Strength 0.50

Controls how strongly parent-child edges pull nodes together.

Root Link Strength 0

Strengthens edges near the root. 0 = disabled.

Age Link Strength 0.00

Additional link strength per million years of divergence. 0 = disabled.

Lock Root Position

Keep the root stationary while the other nodes move.

Wind Direction 0°

0° right, 90° down, 180° left, 270° up.

Wind Strength 0

Directional force applied to the nodes. Zero disables wind.
