WHY THIS MATTERS
================

1. Prevents conflation of taxonomy with evolution
   Problem: Treating taxonomic ranks as equivalent to phylogenetic clades
   Solution: Separate taxonomy (formal classification) from phylogeny (trees)

2. Enables multiple phylogenetic hypotheses
   Problem: Application silently combines competing published trees
   Solution: Hypothesis-scoped node IDs; operations respect boundaries

3. Preserves scientific transparency
   Problem: Estimates averaged or selected silently
   Solution: All estimates with full metadata stored independently

4. Supports constrained layouts
   Problem: Time-axis layout requires architectural refactoring
   Solution: LayoutEngine queries coordinate freedom from start

5. Separates data curation from visualization
   Problem: Dataset collection blocked by visualization code
   Solution: M3 data curation independent; M2 visualization uses test fixtures

6. Eliminates example data confusion
   Problem: Schema examples could be mistaken for real data
   Solution: All examples marked explicitly FICTIONAL


KEY ARCHITECTURAL DECISIONS
============================

Taxonomy Structure:
  - ID prefix: tax_*
  - Example: tax_homo_sapiens
  - Source: ITIS or NCBI Taxonomy
  - Represents formal classification (kingdom → species)

Phylogenetic Hypothesis:
  - Each hypothesis has hypothesisId: "phylo_hypothesis-001"
  - Terminal nodes: type: "terminal", taxonId: references taxonomy
  - Internal nodes: type: "internal", id: ancestor_h1_n0 (hypothesis-scoped)
  - Represents one published evolutionary tree

Divergence Estimate:
  - Binding: (hypothesisId, nodeId, sourceId)
  - Fields: estimateAge, statisticType, uncertaintyType, bounds, methodology,
    calibrationNotes, source DOI, estimate date
  - Multiple estimates preserved; never averaged
  - Display: All estimates available; user selects or app shows most recent

Layout Coordinate Constraints:
  - isXConstrained(): Returns true if X position fixed
  - isYConstrained(): Returns true if Y position fixed
  - Free layout: Both false
  - Time-axis: X=true, Y=false (1D physics on Y)

Synthetic Test Data:
  - Location: test-fixtures/ (within git repo)
  - Clearly marked: All IDs fictional, all data fictional
  - Example: phylo_hypothesis-001, ancestor_h1_n0, tax_example_species
  - Size: 30 taxa for M1 testing
  - Real data: Separate M3 milestone
