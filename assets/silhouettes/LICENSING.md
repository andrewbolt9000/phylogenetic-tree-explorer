### About These Silhouettes

These assets are scientific illustrations created specifically for the PhyloExplorer phylogenetic tree visualization. Each silhouette:

1. **Represents a specific species** with zoologically accurate morphological characteristics
2. **Uses minimalist styling** appropriate for tree node visualization
3. **Maintains consistent visual hierarchy** across all 21 mammals
4. **Scales appropriately** with the Node Circle Size control in the interface
5. **Preserves scientific accuracy** without anatomical distortion

### File Format

All silhouettes are provided as SVG (Scalable Vector Graphics) files:

- **Format**: SVG 1.1
- **Color**: Black fills with `currentColor` support
- **Viewbox**: 100x100 units for consistent scaling
- **Rendering**: Optimized for dark silhouettes on light backgrounds

### Technical Notes

1. **SVG Structure**: Each silhouette uses basic SVG shapes (circles, ellipses, paths) for vector rendering at any scale
2. **Accessibility**: Descriptions are included in each SVG for semantic meaning
3. **Performance**: SVG format provides efficient rendering and small file sizes
4. **Responsiveness**: The Node Circle Size slider controls display size while maintaining visual clarity

### GitHub Pages Deployment

All silhouette paths work under GitHub Pages project subpaths via relative paths:
